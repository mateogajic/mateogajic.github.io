# My Portfolio Website

A personal portfolio website showcasing my projects, skills, and experience as a Physics Engineer.

## 📁 Project Structure

```
portfolio-project/
├── index.html          # Main portfolio page
├── portfolio-2.html    # Alternative portfolio version
├── css/                # Stylesheets folder
├── js/                 # JavaScript files folder
├── assets/             # Images and other media
└── README.md           # This file
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mateogajic/mateogajic.github.io.git
   ```

2. Navigate to the project:
   ```bash
   cd mateogajic.github.io
   ```

3. Open `index.html` in your browser or use a local server

## 📝 Notes

- This is a GitHub Pages site (hosted at mateogajic.github.io)
- All HTML files are in the root directory
- Assets, CSS, and JavaScript files are organized in separate folders
- Features custom cursor styling and dark theme design
