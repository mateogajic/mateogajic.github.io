# Mateo Gajic Sales — Portfolio

Personal portfolio of an Engineering Physics graduate and current master’s student in Quantum Information and Photonics (MUQIP) at Universitat Politècnica de València.

## Files

- `index.html`: main English portfolio, with inline CSS and JavaScript.
- `provisional-index.html`: optional English holding page.
- `og.png`: social sharing image.
- `tools/superpose/`: Superpose qubit simulator, copied from `superpose_v1` with only a “← Portfolio” link and a canonical URL added (marked `portfolio link` in the source). Its PolyForm Noncommercial license travels with it in `LICENSE.md`; `preview.webp`/`preview.jpg` are the card image on the portfolio.
- `cv/Mateo_Gajic_Sales_CV.pdf`: existing downloadable CV supplied with the original archive.

## Preview and publish

Open `index.html` in a browser, or serve this folder with a local static web server.
For the existing GitHub Pages repository, place this folder’s contents in the repository’s publishing source and commit the changes.
